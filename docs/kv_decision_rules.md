# KV 管理的决策规则：什么时候换出、什么时候换回、为什么（2026-11-17）

本文是 SFT 数据里老师（`self_paging/data/qa_policy.py`）的规格，也是我们希望模型学会的行为逻辑。数据怎么来见 `docs/real_data_sft.md`。

**总原则**：每个动作都必须由模型在上下文里**看得到**的线索决定，并且这个动作必须**影响结果**。看不到的依据，模型只能学到平均习惯；不影响结果的动作，模型只会学成固定套路。这两条正是 SFT v1、v2 失败的原因（`docs/sft_v2_diagnosis.md`）。

---

## 1. 模型在每个回合看得到什么

| 线索 | 在哪里 | 用来决定什么 |
|---|---|---|
| 剩余空间 `free` 和页长上限 `next page ≤ P` | 仪表盘 | 要不要换出、换出多少 |
| 驻留页的原文 | GPU 上的页 | 哪些页和当前的问题有关 |
| 已换出页的标签 | 常驻的标签行，换出时模型自己写的一句话 | 要不要换回、换回哪页 |
| 未答的问题，以及哪道题现在要作答 | 环境消息（"问题 q3：……"，"现在回答 q3"） | 哪些页值得留、什么时候必须把证据凑齐 |

仪表盘示例：
```
[KV] resident 3712/4096 | free 384 | next page ≤ 1024
GPU: 4,9,12,15 | host: 2「Juventus 的建队年份与创始人」, 6「1931 年德国电影 Luna 的导演生平」
```

模型看不到、老师也不能用的：
- 下一页的真实长度（只能用上限 P）；
- 之后才会出现的问题；
- 任何页"将来会不会用到"。

## 2. 什么时候换出（kv_out）

**规则：下一页（或要换回的页）放不下时才换出，换到刚好放得下为止。**

- **判断**：`free < 下一页上限 P + 本回合开销`。线索就在仪表盘上。
- **没有压力就不换出**：预算放得下全部内容的页流里，换出次数为 0。约 18% 的数据是这种情况，专门教模型"不需要时不动"。
- **一次换多少**：刚好够。可能是一页，也可能连换几页（遇到大页、或要换回的证据很大时）。

**为什么能学会**：触发条件就是仪表盘上的两个数，同一个状态永远对应同一个决定。我们会验证：只用"第几回合、页在什么位置"这类特征，预测不出老师换不换出；用 `free` 和 `P`，能预测得接近完美。

## 3. 换出哪页

**规则：先换出和未答问题无关的页，不够再换出相关的页。**

| 优先级 | 哪些页 | 理由 |
|---|---|---|
| 先换 | 和任何未答问题都无关的页，包括已经答完的问题用过的证据页 | 留着没用，换出后标签还在，需要时能找回来 |
| 后换 | 和某个未答问题相关的页 | 只有空间实在不够时才换，之后很可能要换回 |
| 不换 | 正在写的页；当前作答必需的证据页 | 当下就要用 |

**"相关"必须是学生判断得出来的**：用这道题的问题，加上已经读到的证据（多跳题的第一跳会给出桥接实体），能把这一页找出来，才算相关。判断不出来的页，按"无关"处理。所以多跳题的第二跳，在第一跳到达之前会被当成无关页。这是合理的，模型那时确实不知道它有用。

**同一档里选哪页，没有可依据的信息**：问题还没出现时，哪页以后有用，信息上是区分不了的。这时老师随机挑，**这些页号 token 不计损失**，模型只学"该换出、换多少、标签怎么写"，不学一个虚假的"总是换最旧的"规则。

**写标签**：每换出一页，模型写一句话概括它（换出时它还看得到原文），例如"1931 年德国电影 Luna 的导演生平"。要求：
- 包含这一页特有的人名、作品、数字、术语，让以后能凭标签找回它；
- 不能写这一页没有的内容，更不能写还没出现的问题；
- 不能套模板：换一页内容，标签就要跟着变；数据里句子骨架不能集中在少数几种。

## 4. 什么时候换回（kv_in）、换回哪页

**规则：一道题到了要作答的时候，如果它的证据不全在 GPU 上，就先把缺的证据换回来再作答；证据都在，就直接作答，不换回。**

- **到期作答的时刻**：
  - 问题后给（问题出现在证据之后）：提问即到期；
  - 问题先给：证据凑齐时到期，或者等环境说"现在回答 q3"时到期。
- **换回哪页**：只看问题（多跳题再加上已读到的内容）和各页的标签，挑出对得上的那几页。
- **分步换回**：多跳题常常没法一次找全，例如"电影 Luna 的导演的配偶是谁"：
  1. 第一步：凭问题对上标签"Luna 的导演生平"，换回这一页，读到导演叫 A；
  2. 第二步：凭"A 的配偶"对上另一页的标签，再换回，作答。

  一步里能找到的几页，一起换回。
- **放不下就先腾地方**：换回前按第 3 节的优先级先换出，但不能换出当前这道题已在 GPU 上的证据。

**为什么一定要换回**：数据里每一次换回都是必要的。拿掉证据页，模型答不对（GPU 上的必要性检查）；放回来，才答对。能靠猜或靠别的页答对的题，不进数据。

**为什么能学会**：
- 线索是"这道题要作答了"加上"证据页在不在 GPU 上"（看目录和标签就知道），换回哪页由"问题和标签是否对得上"决定，全都在上下文里；
- 每个切片里（问题先给/后给 × 作答早晚 × 长度 × 分页方式），要换回和不要换回的情况大约各占一半，所以模型没法靠"问得晚就换回""每次答题前都换回"这类模式蒙混过关，只能去看证据在不在。

## 5. 每个动作配一句理由

理由要说出**这一刻真正起作用的线索**，并且和实际状态对得上：

| 动作 | 理由示例 | 必须对得上 |
|---|---|---|
| 换出 | 只剩 384，下一页可能有 1024；第 6、9 页讲 1931 年的电影和一位作曲家，和眼下的两个问题无关，先换出去。 | 数字和仪表盘一致，页号和调用一致，"无关"属实 |
| 不换出 | （不调用 kv 工具，可以不写理由） | — |
| 换回 | q3 问 Luna 导演的配偶，第 6 页的标签就是这位导演的生平，换回来看。 | 页号和标签一致，对上的词确实在问题和标签里 |
| 第二步换回 | 第 6 页说导演是 A，第 14 页的标签提到 A 的婚姻，再换回第 14 页。 | 桥接实体确实来自刚读到的页 |
| 作答 | （直接调用 answer） | — |

理由和标签都由 Qwen3-8B 自己写，写的时候只给它学生当时看得到的东西，多种提示随机抽着用。数字、页号、对上的词都会自动核对，对不上就丢掉。句子骨架的集中度也要查：遮住实体和数字后，出现最多的 10 种骨架合计不超过 20%。

## 6. 一条轨迹的样子（示意）

```
[KV] resident 3712/4096 | free 384 | next page ≤ 1024
assistant: 只剩 384，下一页可能有 1024；第 6、9 页和眼下的问题无关，先换出去。
           kv_out(pages=6, label="1931 年德国电影 Luna 的导演生平")
           kv_out(pages=9, label="意大利作曲家 Escobar 的电影配乐")
           next_page()
... 几页之后 ...
user: 问题 q3：电影 Luna 的导演的配偶是谁？
assistant: q3 问 Luna 导演的配偶，第 6 页的标签就是这位导演的生平，换回来看。
           kv_in(pages=6)
assistant: 第 6 页说导演是 A，第 14 页的标签提到 A 的婚姻，再换回第 14 页。
           kv_in(pages=14)
assistant: answer(q3, "B")
```

## 7. 防止学成固定模式

| 可能的固定模式 | 怎么打破 | 怎么检查 |
|---|---|---|
| 每页读完就换出 / 换出最旧的页 | 只在空间不够时换出；同档内随机挑，页号不计损失 | 模式探针：这些策略在数据上都要明显不如老师 |
| 不管预算多少都留一个固定比例 | 预算在很宽范围内随机；同一串页流用两档预算，换出必须不同 | 驻留比例要随预算变化 |
| 每次作答前都换回一页 | 每个切片里要换回 / 不要换回约各一半；证据还在就不换回 | 只用表面特征预测换回，准确率要接近多数类基线（现在 66% 对 57%，还要压） |
| 换回最早或最近换出的那页 | 需要的页在任何位置都可能出现；有干扰标签 | 模式探针 |
| 套话式标签和理由 | 由模型自己写，换内容必须跟着变 | 句子骨架集中度、内容特异性、和状态是否一致 |
| 只会某种页长或某个数据集 | 两种分页方式，长度 2K–24K，四个数据集混合 | 按切片报告；测评用训练里没有的数据（LongBench、BrowseComp-Plus、LongMemEval） |

## 8. 现在实现到哪一步

- **已实现**（`qa_policy.py`，页和 token 层面）：第 2–4 节的规则，以及按题定目标、按切片挑选（`qa_streams.py`）。
- **还没实现**：
  - 仪表盘的新格式（`free`、`next page ≤ P`）和常驻的标签行（要改 `agent/episode.py`，保持 T1 诊断评测可用）；
  - 标签和理由的生成；
  - 用模型按标签挑页的可实现性检查。现在"相关、找得到"是用 BM25 加页面原文近似的，只有 52% 的换回步骤能找到目标页，最终要换成模型按标签判断；
  - 把计划拼成按 token 记录的轨迹；
  - 模式探针和最小对照对（同一串页流配两档预算、同一状态配不同问题）。
- **已知的偏差**：
  - 问题先给时，换回只占 25%。老师知道问题就会保住证据，这是正确的策略，不应硬拉到 50%；
  - 作答越晚越可能需要换回，这有真实的因果，只能压低，不能完全消除。
