# SFT 与 RL：数据从哪来、怎么训练

2026-11-15。本文把 [experiment_plan.md](experiment_plan.md) §4（数据）和 §6（RL）展开到可以直接实现的程度。和 experiment_plan 冲突时以本文为准。

前提：
- 动作接口是 tool call：`kv_out`、`kv_in`、`note`，对照条件里加 `kv_drop`；驻留集只在回合之间改变（experiment_plan §2）；
- **策略模型是 Qwen3-8B**（2026-11-15 从 Qwen3.5 改过来，见 experiment_plan v2 §1）。换页作用在全部 36 层；
- 没有外部 API。所有"老师"要么是程序 oracle，要么是**同一个模型加上特权信息**；已经下载好的 Qwen3.5-9B 用作备用老师和评判模型。

## 0. 总览

```
                ┌──────────── "需要"的定义（§1）────────────┐
                │  T1：规则读者的反事实最小充分集             │
                │  T2：evidence/gold 文档 + 显式引用 + 注意力 │
                │       + 反事实 ΔNLL 验证                    │
                └───────────────┬────────────────────────────┘
                                ▼
   需要时刻 + 预算 B ──▶ 按大小加权的 Belady 换页计划
                                │
          ┌─────────────────────┼─────────────────────┐
          ▼                     ▼                     ▼
  A：T1 特权提示生成      B：T2 轨迹重标注        C：协议下的拒绝采样
  （同模型写理由）         （插入 kv 调用并验证）    （1–2 轮专家迭代）
          └─────────────┬───────┴─────────────────────┘
                        ▼
            SFT 混合数据（同题多预算、不换页样本）
                        ▼
              SFT（只为学会协议，越少越好）
                        ▼
  RL 题库：T1 生成器（自适应难度）+ T2 训练 680（难度和"换页敏感度"过滤）
                        ▼
          RL-1（只有 T1）→ RL-2（T1 + T2）→ 消融变体
```

**核心原则**：SFT 只负责让模型学会协议和基本时机；"什么时候换、换哪页"的决策边界交给 RL。原因是 oracle 用了未来信息，模型照抄学到的是无法实现的策略，只能当起点。

## 1. 先定义"一页以后还要不要用"

所有 oracle 和重标注都建立在这个定义上。

### 1.1 T1：规则读者的反事实最小充分集

T1 的每个决策点 d（"新到的货放哪个货架"）都有一个规则读者 R：它只读文本，按规则算出答案，并且已经有测试证明它在完整历史上 100% 正确。

对每个决策点 d，求一个**最小充分集** S_d：

```
S = 决策 d 之前到达的所有页
for p in S（按页长从大到小）:
    if R(S \ {p}) 在决策 d 上的答案 == 正确答案:
        S = S \ {p}
S_d = S
```

- p 属于 S_d，就是"p 在决策 d 时必须驻留"；
- 一页的**需要时刻**就是 {d : p ∈ S_d}；不在任何 S_d 里的页，读完就可以换出；
- S_d 是极小的（去掉任何一页都不够），但不一定是最小的。冗余的页（两页包含同一个事实）只保留一页；
- 测试：对每个 d，R(S_d) 必须给出正确答案，作为规则读者测试的一部分。

### 1.2 T2：三种信号，加反事实验证

BrowseComp-Plus 的每道题都有人工核实过的 **evidence 文档**（回答这道题需要的，平均 6.1 篇）和 **gold 文档**（包含最终答案的，平均 2.9 篇）[S]。一个工具输出页 p 在回合 t 被"需要"，满足以下任一条件即可：

| 信号 | 规则 | 性质 |
|---|---|---|
| ① 人工标注 | p 包含这道题的 evidence 或 gold 文档 → 一直需要到给出答案 | 最可靠，但只覆盖少数页 |
| ② 显式引用 | 回合 t 的文字或工具参数提到 p 里的 docid；或者和 p 有至少 8 个 token 的连续重合；或者对 p 里首次出现的 docid 调用了 `get_document` | 精确，但会漏掉隐式依赖 |
| ③ 注意力 | 在完整上下文的前向里，回合 t 的 assistant token 在 p 上的注意力份额超过阈值 τ（只统计全注意力层） | 覆盖隐式依赖，但有噪声 |

按这些需要时刻做换页计划（§1.3）之后，再做一次**反事实验证**：

```
nll_full = 完整上下文下，每个 assistant token 的负对数似然        # 一次前向
nll_plan = 按换页计划的掩码，同样的 token 的负对数似然            # 一次前向（FlexAttention）
接受这条重标注轨迹，当且仅当：
    mean(nll_plan − nll_full)            ≤ ε1    # 例如 0.02 nats/token
    最终答案那一段的 ΔNLL                  ≤ ε2
    任何一个回合的平均 ΔNLL                ≤ ε3
```

- ε 的标定方法：在同样的轨迹上生成随机换页计划，换出量相同。阈值要能拒掉绝大多数随机计划、留下多数按信号做的计划；
- 这一步检验的正是我们关心的问题：拿掉这些页以后，模型还会不会说出同样的话。验证用的掩码和训练用的掩码是同一套代码（[experiment_plan.md](experiment_plan.md) §5.2）。

### 1.3 换页计划：按页大小加权的 Belady

给定需要时刻和预算 B：

```
每个回合开始时（新页到达后）:
    1. 本回合需要、但不驻留的页 → 换入
    2. 如果驻留量 > B：从"本回合不需要"的页里，按"下次需要时刻"从远到近换出
       （永远不再需要的页排最前；时刻相同时先换出大页），直到 ≤ B
    3. 如果还是 > B：说明 B 小于本回合的最小需要量，这个预算对这道题不可行，记录下来并跳过
```

- 页大小相同时 Belady 是最优的（缺页最少）；页大小不同时它只是一个很强的启发式，文档里要说清楚；
- **笔记变体**：对于以后还要用的页，如果它的活事实可以写成短笔记（T1 里由生成器直接给出结构化事实），就先写笔记再换出；笔记也占预算，并且之后由笔记页代替原页参与"需要"判断。

## 2. SFT 数据

### 2.1 要覆盖的行为

| 行为 | 怎么保证数据里有 |
|---|---|
| 不换页（预算够） | 同一道题在 B = 100% 下的版本，约占 15% |
| 读完就换出（无用页） | T1 的遥测页；T2 里和题无关的搜索结果 |
| 换出后又换回 | T1 的 `delayed` 隔离通知：早到、晚用；T2 里早期看过、后来才用上的 evidence 文档 |
| 写笔记代替原页 | T1 笔记变体 oracle |
| 读仪表盘调整行为 | **同题多预算**：同一个种子或同一道题，在 B = 100%、50%、25% 下各生成一条。这借用了用户原 proposal 里"一题两造"的思路：题目文字完全相同，只有预算和动作不同，迫使模型看预算而不是看题型 |

### 2.2 来源 A：T1 特权提示生成（主要来源）

问题：程序 oracle 能给出动作，但给不出自然的理由；模板理由会让模型学会背模板。

做法：**同一个模型（Qwen3-8B）当老师，给它看特权提示**。连续 4 次不按计划输出时，换 Qwen3.5-9B 当老师；还不行就用模板兜底。

```
对每个 T1 种子、每个预算 B:
    plan = Belady(需要时刻(§1.1), B)                    # 每回合的 kv 动作 + 任务动作
    history = [system, task]
    for 回合 t:
        visible = 按 plan 在回合 t 的驻留集渲染 history（页头 + 驻留页正文 + 仪表盘）
        hint = "[特权提示，不要在回复里提到它] 本回合应执行：kv_out(4,6)，store(item 17 → 货架 3)。
                要点：第 4 页只有遥测；第 6 页的入库记录已被第 9 页更正。"
        for 尝试 in 1..4:
            turn = teacher.generate(visible + hint)          # Qwen3-8B；失败时换 Qwen3.5-9B
            if 工具调用和 plan[t] 完全一致 and 回复里没有"提示/oracle/计划"等字样:
                break
        else:
            turn = 模板理由 + plan[t] 的工具调用           # 兜底，并打标记
        history.append(turn)                              # 存进数据的是不带 hint 的版本
        history.append(环境对 plan[t] 的执行结果)
```

- 要点里的事实（"第 6 页已被更正"）由生成器给出，保证理由是真的；
- 最终数据里没有 hint，模型看到的就是它在测试时会看到的东西；
- 用模板兜底的样本比例应该低于 10%，并且做一组"去掉兜底样本"的消融；
- 规模：约 1000 个种子 × 3 个预算 ≈ 3000 条轨迹；种子 0–9999 用于训练，100000 以后用于测试。

### 2.3 来源 B：T2 轨迹重标注（真实分布）

原料是**完整上下文下答对的轨迹**，有两种：
1. 自己跑：Qwen3-8B 在训练 680 题上，用我们的工具集（search、get_document、answer）、不设预算（开 YaRN），每题采 8 条。用我们自己的渲染格式和 token id，**首选**；
2. ACM 公开的 Qwen3.5-9B 在训练 680 题上的 pass@4 ReAct 轨迹 [R]。模型不同、工具格式不同，要转换后重新分词，分布也和 Qwen3-8B 不一样；只作补充，以及用来粗估题目难度。

流程：

```
for 每条答对的轨迹:
    需要时刻 = §1.2 的三种信号
    for B in {28,672（CLM 的 BCP 设置）, 轨迹峰值长度的 50%}:
        plan = Belady(需要时刻, B)；预算不可行就跳过
        在每次驻留集改变的那个回合，把 kv_out / kv_in 调用追加到该回合的工具调用列表里，
        并插入对应的工具结果和仪表盘行
        反事实验证（§1.2）通过才保留
```

已知偏差（论文里要写）：
- 插入的 kv 调用前面没有专门的推理文字，模型学到的是"顺手换页"，而不是"想清楚再换"；
- 原轨迹是在全部可见的情况下生成的。反事实验证只能保证后续 token 的概率没变，不能保证没有更隐蔽的依赖；
- 做消融："只用 A + C"对比"A + B + C"。

规模：取决于 Qwen3-8B 在 680 题上答对多少，预计几百到一千多条。

### 2.4 来源 C：协议下的拒绝采样（专家迭代）

- 第 0 轮用零样本模型，之后用 SFT 过一轮的模型；
- 在 T1 和 T2 训练集上，在预算 B ∈ {25%, 50%} 下每题采 8 条；
- 只留：答对、协议合法、没有触发超预算截断的；每题最多 2 条；
- 做 1–2 轮。这部分数据最接近模型自己的分布，也最接近 RL 的起点。

### 2.5 混合比例和质量门槛

| 来源 | 数量（条轨迹） | 备注 |
|---|---|---|
| A：T1 特权提示 | ~3000 | 含同题多预算 |
| B：T2 重标注 | 500–1500 | 通过反事实验证的 |
| C：拒绝采样 | 500–1000 | 1–2 轮 |
| 其中 B = 100%、不换页 | 约 15% | 防止模型学成无脑换页 |

自动检查：
- 协议 100% 合法，引用的页号都存在；
- T1：规则读者只读每个决策点的驻留文本（加笔记）就能答对；
- 来源 A 回复里没有提示泄漏；
- 训练集和测试集按题目和种子严格分开，T2 的评测 150 题完全不碰；
- 按题目去重。

### 2.6 可实现性过滤（防止 SFT 教出"未卜先知"）

oracle 是看着未来做决定的。比如它会换出"以后永远用不到"的页，但这一点从这页的内容未必看得出来。照抄这种动作，模型学到的是测试时做不到的事。所以每个 oracle 动作都要过一道检查：

| 动作 | 保留条件 |
|---|---|
| `kv_out` 一个以后不再需要的页 | 理由能从**已经看到的内容**里读出来：这页只有遥测；它的事实已被后面的页取代；它和问题无关（T2 里和问题关键词没有重合，也不是 evidence 文档）。否则改成"预算不紧就不动，预算紧就换出"——反正可逆，换错了还能换回 |
| `kv_in` | 本回合确实要用这页，而且页头或笔记里有线索能指向它（页号、docid、实体名）。T1 里的线索由生成器保证，T2 里检查页头 |
| `note` | 笔记里的事实在源页里能找到（T1 由生成器保证，T2 用字符串匹配检查） |
| LongMemEval 读会话时的动作 | 读的时候不知道问题，**不能用 evidence 会话的信息来决定读时动作**。读时只允许"写笔记 + 换出"或"不动"；特权提示只能出现在问题到达之后，用来决定 `kv_in` 哪些页 |

被改写或删掉的动作要统计比例。比例很高，说明 oracle 依赖的未来信息太多，这份数据要慎用。

### 2.8 T1 SFT 数据：实现和实测质量（2026-11-15）

**实现**（`self_paging/data/build_t1_sft.py` + `oracle/t1_oracle.py`）：每个种子在多个预算下各跑一次 oracle（之后又加了随机难度、`mixed` 模式和恢复样本，见 §2.9），有四种模式：
- `paging`：按需的 Belady；
- `notes`：先写状态笔记再换出；
- `eager`：每回合都把当前状态用不到的页换出，以后需要时再换回，专门产出 `kv_in` 样本；
- `mixed`。

每个回合的文本由三部分组成：
- **作答前**：逐个货架列出状态，例如"S1 occupied, …, S7 quarantined, …, S18 empty and not quarantined. Lowest free shelf: S18"，再调用 `store`；
- **换出时**：每页写明原因，例如"telemetry only""only shelves above S12""quarantine notice""my earlier turn""older note, superseded"；
- **换回时**：说明这次决策需要哪几页；如果驻留的记录不完整、会误导判断，也说明要换出哪几页。

质量门槛：答对；没有非法调用、截断、强制换出、KV 报错；不超预算；作答时可见文本足以推出答案。

**实测**（字符级分词器，40 个种子 × 预算 {1.0, 0.6, 0.45, 0.35} × 三种模式，4 个决策点）：

| 预算 / 模式 | 保留 | 平均回合 | kv_out | kv_in | 笔记 | 含换回的 episode | 依赖未来信息的换出占比 | 峰值 / 预算 |
|---|---|---|---|---|---|---|---|---|
| 0.6 paging | 39/40 | 25.6 | 11.8 | 0.1 | 0 | 10% | 10% | 0.89 |
| 0.6 eager | 39/40 | 26.6 | 14.0 | 1.1 | 0 | 69% | 2% | 0.86 |
| 0.6 notes | 39/40 | 25.5 | 12.6 | 0.0 | 9.4 | 3% | 9% | 0.91 |
| 0.45 paging | 32/40 | 26.7 | 14.9 | 0.7 | 0 | 41% | 17% | 0.89 |
| 0.45 eager | 32/40 | 27.1 | 16.0 | 1.1 | 0 | 66% | 9% | 0.88 |
| 0.45 notes | 39/40 | 25.6 | 15.3 | 0.1 | 11.9 | 8% | 20% | 0.89 |
| 0.35 paging | 18/40 | 28.2 | 17.8 | 1.2 | 0 | 72% | 21% | 0.88 |
| 0.35 eager | 18/40 | 28.5 | 18.9 | 1.5 | 0 | 83% | 14% | 0.88 |
| 0.35 notes | 34/40 | 25.6 | 16.7 | 0.1 | 13.4 | 15% | 31% | 0.86 |
| 1.0（不设预算） | 40/40 | 25.4 | 0 | 0 | 0 | 0% | — | — |

总计 330 条 episode、8661 个 assistant 回合；工具调用：next_events 7179、store 1320、kv_out 4316、note 1285、kv_in 159。

**这一版修掉的问题**（修之前，0.6 预算下的 paging 模式只保留 23/40，kv_in 全部只有 24 次）：
1. **误导性记录**：Belady 逐页决定换出，会拆散成对的记录，例如"S3 出库"那页被换出、"入库到 S3"那页还驻留，读者就以为 S3 有货。现在换出时优先选不改变当前状态读数的页；决策时如果补上缺的页还是推不对，就把可见集合收缩成最小充分集；
2. **几乎没有换回样本**：加了 `eager` 模式；
3. **理由太空泛**：作答理由原来只有一句固定的话，换出理由原来只有"Memory is tight"。

**还存在的问题**（用数据前要知道）：
- **文本是模板**：去掉数字后只有 371 种不同的句式，模型可能学会背模板。缓解办法是 `--teacher` 让真实模型改写理由，见 §2.2；这一步只能在服务器上跑；
- **大约 70% 的回合只是调用 `next_events`**，loss token 只占总 token 的 6–16%。如果 SFT 后模型只会机械地取下一页，可以降低这类回合的权重；
- **笔记是机器格式**（`NOTE-STATE occupied=[…] quarantined=[…]`）：好学，但不自然，迁移到 BCP 时帮助有限；
- **0.35 预算下 paging 和 eager 只保留一半**：多数是预算不够装下决策所需的页；
- **全部是 oracle 数据**，还没有模型自己分布上的样本。SFT 之后要做拒绝采样（§2.4）；
- **上面的数字来自字符级分词器**。换成 Qwen3 分词器后，每页的 token 数大约是现在的 1/4，相对比例应该差不多，但需要在服务器上重新统计一遍。

### 2.9 多样性：有没有换出、换入、反复换出换入（2026-11-15）

**统计方法**（`python -m self_paging.data.inspect_sft --data … --tokenizer …`）：从每条记录的驻留集版本历史里还原出模型发起的每一次换出和换回（系统对仪表盘和回执的维护不算）；同时统计每回合的动作组合（例如"换出 + 取下一页"），以及连续三个回合的动作序列。

**修改前后对比**（字符级分词器，40 个种子，预算 {1.0, 0.6, 0.45, 0.35}）：

| 指标 | v3（§2.8 的版本） | v5（现在） |
|---|---|---|
| episode 数 | 330 | 392 |
| 换回（`kv_in` 换回的页）总数 | 181 | 1121 |
| 有换回的 episode 占比（paging / eager / mixed） | 10–83% | 68–100% |
| 每条 episode 的换回次数（paging / eager / mixed） | 0.1–1.6 | 3.5–5.8 |
| 被换回 ≥ 2 次的页（换出 → 换回 → 换出 → 换回） | 18 | 239 |
| 单页最多换回次数 | 3 | 5 |
| 换出后多少回合换回（中位数 / 最大） | 3 / 20 | 4 / 44 |
| 每回合的动作组合种类 | 7 | 8 |
| 连续三回合动作序列的种类 | 80 | 207 |
| 每条 episode 的决策点数 | 固定 4 | 2–6 |
| 每条 episode 的回合数 | 21–35 | 11–80 |

**做了哪些改动**：
1. **每个种子随机难度**（`--vary`，默认开）：随机抽决策点数（2–6）、关键事件到决策的距离、每页事件数、到货和出库概率；
2. **`mixed` 模式**（默认包含）：每个 episode 随机决定写笔记和主动换出的概率；30% 的情况下，换出单独占一个回合；
3. **失误后恢复的样本**（`--recovery 0.15`，默认开）：在 paging、eager、mixed 模式里，每回合以这个概率故意换出下一个决策要用的页，到决策时再换回。**失误那一回合的 loss 被清零**，所以模型学的是恢复，不学犯错。392 条里有 233 条含这类样本，共 989 个失误回合。

**还缺的**：
- **只有环境页会被换回**，笔记和自己的旧回合从来不会被换回；
- **笔记模式几乎没有换回**（0–8%）：笔记代替了原始页，按设计就不需要换回；
- **动作组合仍然有限**：没有"只写笔记、不换出"的回合，也没有"一回合里换回多次"或者"换回后不作答"的情况；
- **换回大部分来自恢复样本**（1121 次里约 645 次）。模型学到的"换回"会偏向"刚才换错了"这一类；
- **所有数据都来自同一个环境 T1**，题型只有三种（审计更正、盘点、延迟生效的隔离）。

### 2.7 最小 SFT 原则

- SFT 的目的是学会协议，不是学会策略。看 E1 的结果决定 SFT 做多少：
  - **Qwen3-8B 零样本协议合法率 ≥ 80%，并且已经有一些成功的换页**：跳过 SFT，直接 RL（和 CLM 一样从基座开始）；
  - 否则只做 1 个 epoch，然后进 RL。
- 一定要做"SFT + RL"对比"直接 RL"的消融。

## 3. RL

### 3.1 一个 episode

| 项 | T1 | T2-A（BCP） | T2-B（LongMemEval，可选训练） |
|---|---|---|---|
| 初始上下文 | system（含协议说明）+ 任务描述，钉住 | 同左 + 问题 | 同左，**没有问题** |
| 每回合 | 环境推送一页事件；遇到决策点时，模型必须调用 `store(item, shelf)` | 模型调用 `search` / `get_document` / `answer`，工具结果成为新页 | 每个会话作为一页到达，模型有一个短回合；最后给出问题 |
| KV 工具 | `kv_out`、`kv_in`、`note`；不可逆变体只有 `kv_drop` | 同左 | 同左 |
| 预算 B | 每个 episode 从 {25%, 40%, 60%} × 自然长度里抽 | {28,672, 20,000, 14,000} 里抽 | {8K, 16K} |
| 超预算 | **新工具输出被截断到刚好放得下**，仪表盘提示"本次输出被截断 N token"。模型可以先换出再重新调用工具 | 同左 | 同左 |
| 结束 | 所有决策点处理完，或回合数达到 30 | 调用 `answer`；回合数达到 60；或日志达到 120K | 作答 |
| 思考 | 非思考模式（省钱） | 思考模式；思考单独成页，模型可以换出 | 非思考模式 |
| 位置 | 日志 ≤ 32K，不开 YaRN | YaRN factor 4 | YaRN factor 4 |

**为什么超预算时截断，而不是由系统按 LRU 换出**：截断意味着系统不替模型做"留什么"的决定，模型要为显存负全部责任。这样"模型决定"和"系统决定"（Recent、QuestPage 这些基线）的对比才干净。LRU 兜底作为一个消融变体（§3.7）。

### 3.2 奖励

- **T1**：r = 各决策点答对的比例。比起"全对才给 1"，组内方差更大、信号更多；
- **T2**：r = 本地评判模型判定 ∈ {0, 1}。没有调用 `answer` 就是 0。答案里列多个候选的直接判 0，防止钻评判的空子；
- **格式**：不合法的工具调用返回错误信息，不直接扣分；同一个 episode 里非法调用超过 5 次就终止，r = 0，防止死循环。

### 3.3 代价和效率通道

代价按 [algorithm_design.md](algorithm_design.md) §5：

```
C_i = Σ_{生成的 token t} (κ + |R_t|)  +  Σ_{prefill 的 token} (κ_pre + |R|)
```

- |R_t| 是该步读取的驻留 token 数（Qwen3-8B 每层都读）；κ 是把权重读取折算成 KV token 数的常数，取 batch = 32 的值，按 Qwen3-8B 的实际 config 计算（约 16.4 GB 权重 ÷ 144 KB/token ÷ 32 ≈ 3.5K token）；
- 被截断的 token 不计入代价，但截断会让任务更难，由任务奖励来惩罚；
- 效率 advantage 只在组内**成功**的轨迹之间比较（成功少于 2 条的组为 0），只加在 KV 工具调用的 token 上（`ctrl_mask`）：

```
a_eff_i = clip((C̄_succ − C_i) / C̄_succ, −1, 1)
```

### 3.4 优势和损失

```
A_task_i  = r_i − mean_{j∈组} r_j                          # 不除以标准差
A[i, t]   = A_task_i + w_eff · a_eff_i · ctrl_mask_i[t]      # w_eff = 0.25

ρ_t   = π_θ(y_t) / π_old(y_t)
w_t   = min(π_old(y_t) / π_rollout(y_t), 2)                 # TIS，停梯度
L     = − Σ_t w_t · min(ρ_t A[i,t], clip(ρ_t, 0.8, 1.28) A[i,t]) / Σ_t 1    # token 级
```

- 只在 assistant token 上计算损失；工具结果、仪表盘、页头都不算；
- **动态采样**：组内奖励全相同的组直接丢掉，补采新题，保证每步都是有效的梯度（DAPO 的做法）；
- 不加 KL 项；如果 entropy 崩掉或者奖励震荡，再加一个小的 KL（0.001）。

### 3.5 RL 的题从哪来

**T1：生成器，难度自适应**

每个 episode 的参数随机抽：

| 参数 | 范围 |
|---|---|
| 回合数 | 15–40 |
| 每页事件数 | 5–30 |
| 遥测占比 | 0.2–0.7（只增加 token，不增加需要的信息） |
| 决策点数 | 3–8 |
| 关键事件类型 | `explicit`、`implicit`、`delayed` 混合 |
| 事件到决策点的距离 | 短（< 3 回合）、中、长（> 10 回合） |

- 按难度分桶，持续估计每个桶的通过率，只从通过率在 0.2–0.8 的桶里抽题；
- 种子 0–99999 用于训练；测试集用 100000 以后的种子，并单独留一个分布外测试集：回合数翻倍、预算 15%、没见过的事件比例。

**T2：训练 680 题，两道过滤**

1. **难度**：用基座模型在我们协议下 pass@8 的结果（第一次可以先用 ACM 公开的 pass@4 估计），只留 1–7/8 的题；8 次全错的先放一边，等 RL 后期再加回来；
2. **换页敏感度**：同一道题分别跑"不设预算"和"预算 B + Recent 基线"，算通过率差 Δ = p_full − p_Recent@B。Δ ≥ 0.25 的题采样权重加倍。Δ ≈ 0 的题，说明管不管理都一样，对学习换页没有帮助。

- 最多过 3 遍；评测 150 题完全不碰；
- **Qwen3-8B 在 BCP 上可能准确率很低**，组内几乎全是 0，学不到东西。E1 先测训练 680 题上的 pass@8；pass@8 > 0 的题少于 15% 时，按 experiment_plan v2 §3.3 的备选方案（换稠密检索器，或者改用多跳问答做 RL，BCP 只做评测）。

### 3.6 阶段

| 阶段 | 内容 | 步数（起点） | 进入下一阶段的条件 |
|---|---|---|---|
| RL-1 | 只有 T1 | ~200 步，每步 16 题 × 8 | T1 held-out 准确率和代价都稳定；截断率下降 |
| RL-2 | T1 : T2-A = 1 : 3（或备选的多跳问答） | ~1 遍过滤后的 T2 | BCP 评测 150 题上不低于 SFT 后的模型 |
| RL-3（可选） | 只有 T2，更紧的预算 | 视资源 | — |

### 3.7 变体（对应各个假设）

| 变体 | 和主设置的区别 | 用来回答 |
|---|---|---|
| 不可逆 | 只有 `kv_drop`，没有 `kv_in` | K2：可逆性会不会改变策略 |
| 无效率项 | w_eff = 0 | 效率通道的作用 |
| 无笔记 | 去掉 `note` 工具 | K4：写笔记 vs 换页 |
| LRU 兜底 | 超预算时由系统按 LRU 换出，而不是截断 | 模型 + 系统混合管理 |
| 直接 RL | 不做 SFT | §2.7 |

### 3.8 可能的投机行为和防范

| 现象 | 怎么发现 | 怎么防 |
|---|---|---|
| 从不换页，任由截断 | 截断率上升 | 截断会伤害任务，奖励自然惩罚；必要时把截断次数也计入代价 |
| 换出换入来回折腾 | 同一页 3 回合内被换出又换回的次数 | 控制 token 计入代价，效率通道会惩罚 |
| 笔记写得很长，等于把原页抄一遍 | 笔记 token 占比 | 笔记占预算，没有白拿的好处 |
| 不搜索就早早作答 | 平均回合数骤降 | 准确率会下降，奖励惩罚 |
| 钻评判的空子 | 答案长度、候选个数 | 多个候选直接判 0；定期抽样人工看 |
| 思考越来越长 | 每回合 token 数 | 单回合 4096 上限；思考 token 计入代价 |

每步都记录这些指标，加上准确率、平均和峰值驻留量、换回率、rollout 与训练的 log 概率差。

### 3.9 可选：特权信息自蒸馏

在 SFT 和 RL 之间可以加一步密集监督：
- **老师**：同一个模型，上下文里加上 §2.2 那种特权提示（以后要用哪些页）；
- **学生**：当前策略，没有提示；
- 学生自己采样，老师给学生采出的每个 token 打 logprob，按 token 做反向 KL；
- KL 只加在 KV 工具调用的 token 上，避免学生去模仿老师那些依赖提示的推理。

这和 ACM 的 OPD 是同一类方法，区别在于 ACM 的老师是更大的模型（Qwen3.5-397B），我们的老师是"同模型 + 未来信息"。它作为可选项，单独做消融。
