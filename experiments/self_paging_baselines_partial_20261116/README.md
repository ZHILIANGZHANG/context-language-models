## 目前能说明什么

原始模型在这套任务/工具协议上的表现很低，不能直接将与 SFT 的差距归因于 KV 管理策略。共同样本中，Recent 的环境调用错误率约 23.1%–25.7%，QuestPage 约 13.5%–15.5%；记录的这类错误均为 `store_without_pending_decision`，即没有待决策事件时仍调用 `store`。这是对环境状态的错误操作，不是 JSON 格式错误。旧的 `meta.invalid` 字段不涵盖所有此类错误，所以 `invalid≈0` 不代表流程正确。

所有 224 条已完成轨迹中：模型自行输出的内存工具调用审计计数为 0，成功执行的模型 `kv_in/kv_out` 也为 0；未观察到名义 Full 中的隐藏工具调用污染。**源代码中的工具权限执行缺陷仍存在，并未因这批结果没有触发而被修复。** 系统 pager 的换页不是上述模型工具计数，不能把这些 0 解读为系统没有换页。

所有已完成基线轨迹的 `forced_evictions`、`truncated_tokens`、`over_budget` 均为 0；这不等于保留了全部任务相关信息，也不能排除页面策略与任务协议之间的相互影响。两个原始模型基线在已完成世界上均无四次决策全对的世界。SFT 改善了任务流程与工具使用，分离“训练收益”和“KV 策略收益”仍需额外对照；本快照不作显著性、速度或算法优越性结论。

## 设置及证据

- 原始权重 `Qwen3-8B`，无 SFT adapter；Recent 与本项目的 QuestPage 页面 key 摘要近似。不是任意外部实现的完整复刻声明。
- 目标：seed 100000–100049，50 世界 × 3 预算 × 2 方法 = 300 次。每世界四次决策。
- 与 SFT 相同的环境正文、题目、预算函数及采样配置：temperature=0.6、top_p=0.95、top_k=20、按世界 seed 初始化采样器、max_turns=60、max_new_tokens=1024，非 thinking 格式。
- 预算为固定模板开销 + 系数 × 环境正文 token 数，不是显存百分比。
- SFT 对照来源：[已经发布的完整 SFT 归档](../self_paging_20261116/README.md)。不加入存在明确污染的名义 Full 91% 行。
- 实际源码和调度器已在提交 `cbdf9fc2faf39f7730a876f9c1393281d15365ca` 发布。此次收集再次校验 93 个源文件及相关 helpers 的 SHA；没有部署源码变更。
- `jobs/` 保存各分片的完整结果行前缀、启动及已存在的退出/完成记录。`raw/` 保存这些结果引用的原始 gzip，逐文件散列与服务器完全一致；包含三条已完成旧 Recent 轨迹的明确复用来源。
